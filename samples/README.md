# Sample files

`sample-bank-statement.csv` is a **fictional** one-month bank statement in the
layout many Indian banks use for CSV exports: a short preamble, then Date,
Narration, Ref No, Withdrawal Amt, Deposit Amt and Closing Balance columns.
Names, UPI IDs and reference numbers are invented.

Use it to try the import flow: sign in, open **Imports**, and upload the file.
It exercises salary credit, rent, food delivery, small repeated payments,
a SIP, bills, a self transfer, a refund and a cashback.

`sample-google-pay-statement.pdf` is a **fictional** Google Pay style
statement (five UPI payments across two pages, with a page header, a summary
and footers). It is built from public descriptions of the layout, not from a
real statement. It is not password protected.

`sample-bank-statement.xlsx` is a **fictional** Excel export with a cover
sheet and a preamble above the table. Its Swiggy payment carries the same UPI
reference as the one in the Google Pay sample, so importing both shows
duplicate detection across sources.

The PDF and Excel samples are generated by `apps/api/test/fixtures/statements.ts`;
the CSV was written by hand.
